# NeuroChat AI

NeuroChat AI is a cutting-edge, startup-level AI chatbot web application featuring an ultra-modern, animated, and futuristic interface.

## Features

- **Modern UI**: Next.js 14, Tailwind CSS, ShadCN, Framer Motion, and Three.js for a stunning, glassmorphism-inspired dark mode theme.
- **Real-time AI Chat**: Node.js/Express backend with WebSockets for fast, streaming responses.
- **Robust Backend**: MongoDB for chat history and user management.
- **Intelligent Conversations**: OpenAI API integration for advanced context memory.

## Getting Started

### Prerequisites

- Node.js (v18+)
- MongoDB

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Nikhil0-1/neuro.git
   ```

2. Setup Backend:
   ```bash
   cd neuro/backend
   npm install
   # Configure your .env file
   npm run dev
   ```

3. Setup Frontend:
   ```bash
   cd ../frontend
   npm install
   # Configure your .env.local file
   npm run dev
   ```
